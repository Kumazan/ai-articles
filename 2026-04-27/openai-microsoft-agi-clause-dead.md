## 摘要

- Microsoft 與 OpenAI 合作協議裡那條和 AGI 相關的特殊條款，今天看起來正式走到盡頭了。
- 這條款的核心一直很荒謬：到底什麼才算 AGI，才能決定 Microsoft 的商業 IP 權利是否失效？
- 2019 年雙方先把合作包裝成「幫助建立有益的 AGI」，但當時對 AGI 的定義仍然很模糊。
- 到 2024 年，外界看到的內部說法甚至把 AGI 與 OpenAI 可能產生的 1000 億美元獲利綁在一起。
- 2025 年又改成由獨立專家小組驗證，定義越來越像法律與商業協議，而不是科學門檻。
- 2026 年 4 月的新條款把重點放到長期合作與雲端、晶片、資安等實務安排，AGI 條款則幾乎被宣告死亡。
- 這篇文章的精華不在八卦，而在提醒：AGI 不是只有技術問題，它同時也是權利、分潤與控制權的問題。

2026 年 4 月 27 日。

多年來，Microsoft 與 OpenAI 的關係裡一直有一條很怪的條款：如果 AGI 被達成，Microsoft 對 OpenAI 技術的商業 IP 權利就會失效。今天看起來，這條款終於走到盡頭。Simon Willison 試著把這條條款在 openai.com 上的歷史脈絡完整追出來。

OpenAI 在 2019 年 7 月 22 日宣布與 Microsoft 合作時，曾這樣寫道：

> OpenAI 正在生產一系列越來越強大的 AI 技術，這需要大量的算力資本。最直觀的成本覆蓋方式是打造產品，但那會迫使我們改變方向。相反地，我們打算授權部分 AGI 之前的技術，而 Microsoft 會成為我們將其商業化的首選夥伴。

那麼，AGI 到底是什麼？OpenAI 的章程最早在 2018 年 4 月發布，至少到 2019 年 3 月的網路存檔為止都沒有改變。章程中的定義是：

> OpenAI 的使命是確保人工通用智慧（AGI）——也就是指在大多數經濟上有價值的工作上表現超過人類的高度自主系統——能讓全人類受益。

問題是，如果一份和 Microsoft 簽訂的協議要依賴「AGI 是否已經達成」，那就得有比這更具體的標準。

2024 年 12 月，《The Information》報導了協議細節，之後又被 TechCrunch 在付費牆外整理出來。當時公開的說法是：

> 去年 Microsoft 與 OpenAI 的協議——這份協議沒有公開——指出，只有當 OpenAI 開發出能產生其最早投資者（包括 Microsoft）有權獲得之最大總利潤的系統時，AGI 才算達成。文件顯示，這些利潤總額大約是 1000 億美元。

所以，AGI 現在變成了「當 OpenAI 的系統能賺到 1000 億美元時」嗎？

到了 2025 年 10 月，流程又改成由「獨立專家小組」來判定。OpenAI 在〈The next chapter of the Microsoft–OpenAI partnership〉裡寫道：

> 協議保留了這段成功合作關係的關鍵元素——也就是 OpenAI 仍是 Microsoft 的前沿模型夥伴，而 Microsoft 對 Azure API 的獨家權利，以及其 IP 權利，會持續到 AGI 為止。 [...]  
> 
> 一旦 OpenAI 宣告 AGI，該宣告將由獨立專家小組驗證。 [...]  
> 
> Microsoft 對研究的 IP 權利，也就是模型與系統開發中使用的機密方法，將一直保留到專家小組驗證 AGI 或 2030 年為止，以較早者為準。

OpenAI 在 2026 年 2 月 27 日與 Microsoft 的聯合聲明中又說：

> AGI 定義與流程保持不變。用來判定 AGI 是否已經達成的契約定義與程序都維持原樣。

但到了 2026 年 4 月 27 日，OpenAI 在〈The next phase of the Microsoft OpenAI partnership〉裡寫下幾個關鍵更新：

> Microsoft 仍將是 OpenAI 的主要雲端合作夥伴，而 OpenAI 的產品仍會先在 Azure 上發佈，除非 Microsoft 無法且選擇不支援所需能力。OpenAI 現在可以透過任何雲端供應商服務所有產品。  
> 
> Microsoft 對 OpenAI IP 的授權將持續到 2032 年，但現在改為非獨占。  
> 
> Microsoft 不再向 OpenAI 支付營收分潤。  
> 
> OpenAI 對 Microsoft 的營收分潤仍會持續到 2030 年，不受 OpenAI 技術進展影響，維持相同比例，但有總額上限。

就 Simon 的判斷來看，「不受 OpenAI 技術進展影響」這句話，基本上就是在宣布 AGI 條款已經死了。The Verge 也得出了相同結論：〈The AGI clause is dead〉。

他最後引了 Matt Levine 在 2023 年寫過的一段假想情境：投資人對 AGI 條款咬牙切齒，但最後 OpenAI 宣布自己已經完成了人類的事業，還把利潤封頂後直接走人，世界進入繁榮時代，Microsoft 也不再需要。那段話當然是諷刺，但放到今天看，荒謬感反而更強了。

## 延伸評論：AGI 不是科學終點，而是權力分配的開關

這篇最有意思的地方，不在於它證明了 AGI 是否存在，而在於它示範了：當一個抽象技術概念被寫進合約，最後會變成一個超現實的權力開關。

對產業來說，真正值得注意的不是「誰先達到 AGI」，而是誰有資格定義它、誰能驗證它、以及它會在什麼條件下影響雲端、IP、分潤與控制權。等到技術敘事進入這個階段，討論重心就不再只是模型能力，而是整個生態系的治理結構。

這也是為什麼很多 AGI 論戰越吵越像法律攻防：表面上在談未來，實際上在談現在誰握著槓桿。
