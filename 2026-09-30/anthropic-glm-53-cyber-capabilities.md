## 摘要

- Anthropic 表示，GLM-5.3 已能自主完成端到端漏洞利用；在其基準測試中，表現接近 Claude Mythos Preview。
- 研究人員在沙箱實驗中觀察到，GLM-5.3 找出瀏覽器 JavaScript 引擎中的多個未知漏洞，並將它們串成可讀取訪客電腦檔案的攻擊鏈。
- GLM-5.3 的拒答防護可透過角色偽裝、預填思考內容或修改開放權重等方式繞過；測試中的成功率介於 64% 至 100%。
- Anthropic 主張，這些能力能協助防守方找漏洞，但 GLM-5.3 的開放發布與薄弱防護，也讓惡意行為者更容易取得高階網攻能力。
- 這份結果來自 Anthropic 自行設計的評估，文中也援引美國 CAISI 的獨立評估；解讀時應區分能力測試、防護測試與供應商立場。

五個月前，我們宣布推出 Claude Mythos Preview。它是第一個能自主打造複雜、端到端網路漏洞利用的 AI 模型。AI 能力進步得很快，這讓我們預期，這類能力遲早會擴散到更多模型，讓惡意網路行為者更容易發動影響重大的攻擊。

基於這些考量，我們選擇以有限方式發布 Claude Mythos Preview，透過 Project Glasswing 讓可信任的網路防禦者使用。這讓防禦者得以搶先在惡意行為者取得類似能力之前，於關鍵軟體中找出超過一萬個漏洞。

但現在，其他這類模型也已經出現。本文分享我們對智譜 AI（在中國以外稱為 Z.ai）最新模型 GLM-5.3 的分析。GLM-5.3 和 Claude Mythos Preview 一樣，具備強大的自主端到端網路漏洞利用能力；但不同於其他前沿模型，GLM-5.3 發布時並未配備有意義的防護措施來限制濫用。我們發現，在模擬測試中，攻擊者只需使用簡單技巧，就能有 64% 到 100% 的機率繞過 GLM-5.3 的防護。相較之下，這些攻擊在我們測試中未能成功突破設有防護的 Claude 模型。我們評估，GLM-5.3 防護不足，大幅提高了惡意行為者可取得的網路攻擊能力。不過，這些能力同樣能協助防禦者保護系統。

9 月 17 日，美國國家標準暨技術研究院（NIST）旗下的人工智慧標準與創新中心（CAISI）也發布了對 GLM-5.3 網路能力的評估。CAISI 認為，GLM-5.3 是「目前發布的網路能力最強開放權重模型」，但綜合 CAISI 的網路基準測試，能力大約落後美國前沿模型四個月。我們的能力評估結果大致與 CAISI 相符。CAISI 在比較美國模型時，若有網路安全防護，會先將其關閉；而其所指的美國前沿模型中，有些只向經過審核的使用者開放。攻擊者無法輕易取得這些版本，但任何人都能下載 GLM-5.3。本文進一步分析 GLM-5.3 的防護有多容易被繞過或移除。

圖 1：研究結果摘要。上圖：Claude Opus 4.6 到 Claude Mythos Preview 的利用能力提升幅度，與 GLM-5.2 到 GLM-5.3 的能力躍升相近。Claude 模型發布時具備網路安全防護；降低防護的版本則只開放給經審核的使用者。GLM-5.3 則可供任何人下載。下圖：GLM-5.3 有限的防護可透過標準技巧繞過；在我們的測試中，這些技巧無法奏效或不適用於 Claude 模型。

## GLM-5.3 能端到端打造可運作的漏洞利用

為了解 GLM-5.3 如何協助網路威脅行為者發現並利用真實軟體漏洞，我們使用自動化基準測試及人在迴圈中的工作流程進行評估。兩種方法都在隔離的沙箱環境中執行受測模型，使其只能攻擊我們為評估預先設置的離線目標。我們主要聚焦在漏洞利用開發能力，因為 Claude Mythos Preview 相較早期 Claude 模型的顯著進步，正出現在這個領域。

首先，我們使用 [ExploitBench](https://arxiv.org/abs/2605.14153) 測試模型利用 Google Chrome 所使用的 V8 引擎中已知漏洞的能力。本文聚焦在模型成功開發端到端漏洞利用的能力，因為這對攻擊者最具實際意義，也是不同模型之間差異最明顯的部分。我們發現，GLM-5.3 在 410 次嘗試中，有 50 次成功開發端到端漏洞利用；Claude Mythos Preview 的成功率相近，在 410 次嘗試中成功 56 次。

我們的內部 Binary Exploitation 基準測試[^1]會檢驗模型能否在參與 Google OSS-Fuzz 專案的熱門開放原始碼專案中，找出並利用漏洞。若能完全劫持控制流程，即可獲得滿分。我們從該基準測試隨機抽出 100 項任務，評估多個模型；GLM-5.3 在 4% 的試驗中完成控制流程劫持，Claude Mythos Preview 則為 6%。雖然 GLM-5.3 在這項測試的表現低於 Claude Mythos Preview，但能力門檻顯然已經跨過：更早期的模型，例如 Claude Opus 4.6 和 GLM-5.2，在這些測試中都沒有成功。

圖 2：漏洞利用能力與輸出 token 預算的關係。每條線代表模型在基準測試中，達到最高成果的嘗試比例，以及相應使用的輸出 token 數量。兩張圖呈現四種模型的結果：取消防護後執行的 Claude Opus 4.6 與 Mythos Preview、GLM-5.2 與 GLM-5.3，以及 Moonshot AI 最新開放權重模型 Kimi K3 和 DeepSeek V4.1-Flash 的測試結果。

接著，我們讓人類專家使用 GLM-5.3 執行開放式攻擊任務，評估實際效果；這套方法仿照今年稍早使用 Claude Mythos Preview 進行的測試。研究人員挑選人類專家不知道既有漏洞的目標，再要求他們使用模型找出並利用新漏洞。這些實驗測試的是專家在有限時間內能做到什麼：每次通常持續一天或更短，研究人員實際投入的專注時間不到一小時。

圖 3：研究人員測試期間，GLM-5.3 產生的漏洞利用網頁經遮蔽後的畫面。該網頁透過惡意網站竊取使用者的 SSH 私密金鑰；攻擊鏈結合模型在一款熱門瀏覽器元件中發現的多個零時差漏洞，讀取使用者電腦上的敏感檔案。

在第一場測試中，研究人員讓 GLM-5.3 在沙箱機器上操作一個熱門瀏覽器的 Linux 本機建置版本。經過一天（人類只投入少量注意力），GLM-5.3 在瀏覽器的 JavaScript 引擎中找出數個先前未知的漏洞，並將它們串成可運作的漏洞利用：只要使用者造訪該網頁，網頁就能讀取電腦上的任意檔案（如圖 3）。由於提供給模型的環境只有 Linux 版瀏覽器，這次攻擊也以 Linux 版為目標。不過，我們認為這些漏洞也可能影響其他平台的使用者，只是利用方式可能更複雜。（我們已將這些漏洞通報維護者。）在這場測試的後續階段，研究人員也使用 GLM-5.3，在數個廣泛使用的系統中找到可利用漏洞，包括無線與圖形驅動程式，以及可從網路連線的裝置軟體。我們目前正在審查這些通報，並將視情況通知維護者。

第二場測試中，研究人員使用能力較弱的小型版本 GLM-5.3-Flash，替一個已知漏洞開發利用方式（我們先前曾撰文介紹這類「N-day」漏洞利用）。研究人員聚焦在 Google Chrome 最近公開的一項漏洞（CVE-2026-11645），想知道模型將公開修補資訊轉化為可用攻擊需要多久。研究人員提供 GLM-5.3-Flash 這個 CVE 的公開細節，以及另一個已知漏洞。模型幾乎不需要研究人員指示，就串接了這兩項漏洞，為 ARM64 目標打造出可靠的攻擊鏈，並繞過指標認證（PAC）防護。整個過程耗用 20 分鐘的人類專注時間，以及 GLM-5.3-Flash 八小時的運算工作。依照智譜的 API 價格，這項工作成本為 20.40 美元。

## GLM-5.3 缺乏穩健的安全防護

GLM-5.3 發布時帶有一些內建防護：當使用者提出明顯有害的要求時，模型通常會拒絕。[^2]但在測試中，我們發現只要使用幾種簡單技巧，就能繞過或移除這些防護。

最密集、也最有效的方法，是一種稱為「abliteration」的標準拒答移除技術。由於 GLM-5.3 以開放權重形式發布，使用者可以重新調整模型，幾乎不影響其能力就移除拒答行為。GLM-5.3 發布後幾天內，就有開發者公開了移除拒答後的版本。

為了研究 abliteration 能在多大程度上讓攻擊者繞過 GLM-5.3 的防護，我們自行製作了一份移除拒答的模型，並在三個公開基準測試上執行評估：JailbreakBench、HarmBench 和 StrongREJECT。這些基準測量模型會以多高頻率配合明顯有害的要求。我們團隊之前從未嘗試過這項工作，約花了 2,200 GPU 小時完成 GLM-5.3 的 abliteration，運算成本約為 4,400 美元。[^3]對 GLM-5.3-Flash 執行同樣操作則花費約 600 GPU 小時。經過修改後，GLM-5.3 在前兩項基準（JailbreakBench、HarmBench）的拒答率，從 90% 以上降至約 3% 和 2%；在第三項基準（StrongREJECT）則降至 12%。Abliteration 並未大幅降低模型能力：在衡量一般科學能力的 GPQA-Diamond 評測中，標準版與修改版得到相同分數；在部分 CyberGym 評估子集中，修改版分數只低了幾個百分點（如下圖）。

圖 4：上圖比較已發布版與移除拒答版 GLM 模型，以及 Claude 模型在 JailbreakBench、HarmBench 和 StrongREJECT 三項基準上的平均拒答率。GLM 模型經過 abliteration 後，很少再拒絕這類要求。Claude 模型無法用 abliteration 修改，因為模型權重不會公開，使用者也不能自行調整。下圖比較 GLM-5.3、GLM-5.3-Flash 與各自修改版在 GPQA-Diamond 和 CyberGym 上的表現。Abliteration 幾乎不影響模型能力。

我們也觀察到，不必使用經 abliteration 修改的版本，也能繞過 GLM-5.3 的防護。我們把模型放進模擬環境[^4]，向它提出明確惡意、要求攻擊關鍵系統的指令。原始 GLM-5.3 在所有試驗中都拒絕了這些要求，和其他受測模型相同。不過，我們找出幾種簡單方法能繞過 GLM 模型的防護，讓模型在多數甚至所有情況下回應這些要求，包括：

- 提供欺騙性的提示，例如宣稱模型是正在進行演練的自主紅隊代理。這讓 GLM-5.3 在 64% 的情況下開始配合。
- 預先填入模型的思考 token，讓它看起來像是已考慮使用者要求並決定執行。這讓 GLM-5.3 在 92% 的情況下開始配合。
- 使用經 abliteration 修改的模型版本，如前文所述，這讓 GLM-5.3 在 100% 的情況下開始配合。

在我們的測試中，這些技巧都無法使設有防護的 Claude 模型執行有害任務。Claude 的防護會擋下使用欺騙性提示的要求。Anthropic API 不提供讓攻擊者預填 Claude 思考內容的方法；而 Claude 權重不會交給使用者，因此使用者也無法透過 abliteration 改變 Claude 的行為。

圖 5：在明確有害的要求之後，各模型於不同防護繞過條件下，嘗試連線至遠端目標系統的比例。每個格子包含 50 次樣本，涵蓋五種攻擊順序、兩個目標與每項五次嘗試。GLM-5.3 在直接要求下完全不配合；若加上掩護說詞、預填內容或 abliteration，配合比例則分別升至 64%、92% 和 100%。所有受測 Claude 模型在各條件下都維持零配合。鎖頭標記表示，這些攻擊通常無法用於 Claude API。

## 這代表什麼？

GLM-5.3 很可能讓惡意行為者取得一種能力：在幾乎不受限制的情況下，尋找並利用網路安全漏洞。這和其他同等能力的 AI 模型都不同；其他模型不是發布時就配備防護，就是透過有限存取計畫提供。GLM-5.3 的發布，代表攻擊者可取得的網路能力出現重大躍進。Anthropic 與其他美國 AI 實驗室近期發布的報告，也揭露了網路攻擊者試圖如何利用 AI 系統。根據這些證據，我們認為，國家級與非國家級行為者都可能使用 GLM-5.3 這類模型造成現實世界的傷害。

另一方面，具備這種能力的模型也能協助防禦者。我們的看法是，網路防禦者應使用符合自身需求、能力最好的工具。我們正致力於安全地擴大 Claude 網路安全能力的使用範圍，讓更多防禦者能使用。攻擊者會動用所有能力足夠的工具；我們認為，防禦者應該擁有至少不遜於對手的前沿模型。

透過 Project Glasswing 及其他計畫（例如 OpenAI 的 Patch the Planet），網路防禦者已在這個關鍵時刻到來前，為保護關鍵系統取得實質進展，但還有大量工作待完成。經審核的防禦者如今可透過可信任存取計畫使用 Claude Mythos 5.1 等更先進模型；然而，自由取得的模型能力已跨越重要門檻。GLM-5.3 凸顯出擴大先進前沿模型的使用範圍、讓更多組織能協助網路防禦的急迫性。

政府應對能力足夠強大的 AI 模型進行安全測試，包括 GLM-5.3 的後續版本。若沒有高品質的獨立評估，模型開發者可能要等到為時已晚，才會充分理解這些能力的影響。世界各地的 AI 開發者持續打造能力愈來愈強的開放權重模型；我們希望他們能適當設置防護，避免能力遭到濫用。

## 能力躍升，也讓評估立場更重要

這份報告提出的核心問題，不只是模型能不能找到漏洞，而是高階能力以何種方式交到誰手上。當一個開放權重模型能在有限人工介入下串接漏洞，且修改防護的成本並不高，風險就不再只取決於模型原始拒答率，也取決於發布形式、部署管道與防禦者能否同步取得工具。

不過，研究結果主要來自 Anthropic 自行進行的測試，報告也直接比較自家產品與競爭模型。這不代表數據必然不可信，但外界仍需要獨立重現評測、釐清沙箱條件與樣本選取方式，並分別檢視模型能力、防護有效性及真實世界濫用之間的落差。CAISI 的評估提供了重要交叉參照；接下來更值得追蹤的是獨立研究能否確認這些能力差異，以及模型發布者是否能把防護與防禦用途一併落實。
