## 摘要

- Anthropic 這次不是只談模型能力，而是直接把 Claude 接進創意產業常用的工具鏈。
- 新增的 connector 涵蓋 Blender、Autodesk Fusion、Adobe、Ableton、Splice、SketchUp、Resolume 等軟體。
- 核心方向很清楚：讓 Claude 能查文件、改檔案、寫腳本、整理資產，減少創作流程中的手動搬運。
- 對 3D、設計、音樂與 AV 工作來說，這比單純多一個聊天介面更有實際價值。
- Anthropic 也把 Blender Development Fund 納入合作，強調 MCP 與開源互通性。
- 這篇文章的訊號是：AI 產品競爭正在從「誰比較會講」轉向「誰能真正接上工作流」。

<div class="sep">· · ·</div>

創意工作者會期待技術幫助自己把可能性打開。Claude 不會取代品味或想像力，但它可以帶來新的工作方式——更快、更大膽的發想、更廣的技能範圍，以及承接更大規模專案的能力。AI 也能分擔創作流程中那些吃掉時間的部分，像是重複性任務與繁瑣的人工作業。要讓這兩個目標都成立，關鍵就是把 Claude 整合進創意產業本來就熟悉、也信任的工具裡。

今天，Anthropic 與 Blender、Autodesk、Adobe、Ableton、Splice 等合作夥伴一起，推出一組 connectors——也就是讓 Claude 能直接跟創意專業人士常用的軟體協作的工具，讓創作者可以把觸角延伸得更遠。

## 讓 Claude 接上創意工具

Connectors 讓 Claude 可以直接存取其他平台與工具。這次新增的幾個 connectors，目標是讓 Claude 更容易用在創意工作上：

- [Ableton](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/ant.dir.gh.ableton.ableton-knowledge) 會把 Claude 的回答建立在 Live 和 Push 的官方文件上。
- [Adobe for creativity](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/adobe-creativity) 讓使用者能把影像、影片與設計作品做得更完整，並可調用 Creative Cloud 裡 50 多個工具，包括 Photoshop、Premiere、Express 等。
- [Affinity by Canva](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/ant.dir.gh.canva.affinity) 可自動化專業創作流程裡的重複性工作，例如批次調整圖片、重新命名圖層、匯出檔案，還能在 App 內直接產生客製化功能。
- [Autodesk Fusion](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/ant.dir.gh.autodesk.fusion-mcp) 讓擁有 Fusion 訂閱的設計師與工程師，能透過和 Claude 對話來建立與修改 3D 模型。
- [Blender](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/ant.dir.gh.blender.blender-mcp) 提供一個自然語言介面連到它的 Python API，方便使用者探索複雜設定，也更容易查閱 Blender 文件。
- [Resolume Arena](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/ant.dir.gh.resolume.resolume-arena) 和 [Resolume Wire](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/ant.dir.gh.resolume.resolume-wire) 讓 VJ 和現場視覺藝術家能在即時演出與 AV 製作中，用自然語言控制 Arena、Avenue 和 Wire。
- [SketchUp](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/sketchup) 能把和 Claude 的對話變成 3D 建模的起點——描述一個房間、一件家具或一個場地概念，再把結果帶進 SketchUp 進一步修整。
- [Splice](https://claude.ai/redirect/website.v1.0152defa-1c5a-445d-adf3-93d1911a1b85/directory/connectors/splice) 則讓音樂製作人能直接在 Claude 裡搜尋它的免版稅 sample 資料庫。

## Claude 可以怎麼用在創作上

這裡列出幾種 Claude 能派上用場的創作任務：

- 學習與掌握創意工具：Claude 可以當成隨叫隨到的導師，幫你理解複雜軟體。可以請它解釋 modifier stack、帶你走一遍合成技巧，或示範不熟悉的功能，它會一步步教你怎麼用。
- 用程式擴充工具：Claude Code 可以替你寫腳本、外掛與生成式系統，對應你已經在用的軟體。像是建立自訂 shader、寫程序動畫腳本，或產生 parametric model，它都能輸出可重用、可修改的文件化程式。
- 串起整條工作管線：Claude 可以翻譯格式、重組資料，並讓跨越多個應用程式的專案維持資產同步，讓設計、3D 與音訊工具之間的搬運少掉很多手工步驟。
- 加速探索與交接：Claude Design 是 Anthropic Labs 的新產品，可用來探索軟體體驗的構想。Claude 能把選項視覺化，並根據回饋反覆迭代；它也已經能把結果匯出到其他工具，起步支援 Canva。
- 接手重複性的製作工作：Claude 可以處理像是批次處理素材、建立專案骨架，或在場景裡套用程序化修改這類多步驟任務，減少雜務。

## Claude 與 Blender

Blender 是一套免費、開源的 3D 創作工具，橫跨 indie game 開發、動態圖像、建築視覺化與電影製作等領域。

Blender 開發者已經建立一個 MCP connector，現在 Claude 可以正式使用它。舉例來說，3D 藝術家可以用 Blender connector 來分析與除錯整個 Blender 場景，或寫自訂腳本批次修改場景中的物件。而且透過 Blender 的 Python API，這個 connector 也能讓 Claude 把新工具直接加進 Blender 的介面。

Anthropic 也已加入 Blender Development Fund，成為贊助夥伴，支持 Blender 持續開發它的 Python API；正因如此，像這樣的整合才有可能成立。而且這個 connector 建在 [MCP](https://modelcontextprotocol.io/docs/getting-started/intro) 上，因此不只 Claude 能用，其他 LLM 也能存取，這也反映出 Blender 對開源與互通性的承諾。

## 與學生和教育者合作

Anthropic 也正在和藝術與設計課程合作，支援涉及 creative computation 的課綱。第一批合作單位包括 Rhode Island School of Design 的 Art and Computation、Ringling College of Art and Design 的 Fundamentals of AI for Creatives，以及倫敦大學 Goldsmiths 的 MA/MFA Computational Arts program。學生和教職員會獲得 Claude 與這些新 connectors 的使用權，而他們的回饋也會幫助 Anthropic 了解創意實務真正需要什麼。未來也會持續把這個計畫擴展到更多學校。

## 延伸評論：創意 AI 的勝負手，不是「能不能畫」，而是能不能接進流程

這篇最值得注意的地方，不在於 Claude 會不會又多了幾個看起來很酷的 demo，而是它把戰場往更現實的地方推了一步：創意工作真正的成本，常常不是靈感，而是格式轉換、資產同步、批次整理與工具切換。

如果 AI 只能待在聊天框裡，它對創作者的幫助終究有限；但一旦能直接讀文件、寫腳本、動工具、處理重複製程，價值就會從「輔助聊天」變成「縮短整條管線」。這也是為什麼 connectors 這類東西比單次生成更關鍵。

對設計、3D、音樂和現場視覺工作者來說，接下來真正要看的不是模型分數，而是誰能把 AI 做成可信任、可控、可交接的工作夥伴。
